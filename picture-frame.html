Picture Frame Mode

Your photos, on display

Turn an old laptop or a Raspberry Pi into an always-on digital picture frame — controlled entirely from your phone, no app to install.

Always-on, unattended

  • Launch with --background and the window stays hidden until someone presses Start Show from a phone or browser on the same network.
  • If the power drops and the device boots back up, picture show 3 resumes the show on its own — no log-in, no click, no settings screen.
  • A built-in periodic rescan picks up new photos dropped into the folder (locally or over a network share) without ever interrupting the show.
  • The same HTTP endpoints the smartphone uses are exposed publicly, so Home Assistant, a shell script, or any other tool can drive the frame.

Control from any phone

Web-based remote

Scan the QR code or open the frame's URL in any browser on the same Wi-Fi. No app to install, no account to create — the slideshow itself serves the page.

  • Live 16:9 preview of the current image that cross-fades on every change.
  • Image counter, star rating, and caption shown right under the preview.
  • Prev / Next / Play, autoplay interval slider, and on-screen Info Bar / Details toggles.
  • Works from iOS, Android, or a laptop — anywhere a browser runs.

Configure the frame remotely

Picture-frame tab

A second tab in the web UI is dedicated to the long-running, hands-off use case. Start and stop the show, tweak playback, and schedule background scans without ever touching the device itself.

  • Start Show / End Show — bring the frame up or send it back to standby.
  • Autoplay interval slider from 10 s to 24 h on a non-linear scale.
  • Image scale: Fit (letterboxed) or Fill (cropped) — chosen at a tap.
  • Transition style: Fade, Slide, Zoom, or Fade-to-black.
  • Background rescan every 5 min, hour, half-day, or anything in between — or off entirely.

HTTP API

The same endpoints the phone calls are also yours to script. Wire the frame into Home Assistant, a sunrise / sunset cron, a doorbell event — anything that can make an HTTP request. 

# Start the show
curl http://picture-frame.local:8765/control/start

# Stop the show (plays the leave animation, then hides the window)
curl http://picture-frame.local:8765/control/stop

# Set autoplay interval to 30 seconds
curl "http://picture-frame.local:8765/control/interval?value=30000"

# Trigger a manual rescan of the source folder
curl http://picture-frame.local:8765/control/rescan

# Get JSON status (playing, current index, caption, rating, …)
curl http://picture-frame.local:8765/status

DIY: Build your own

A Raspberry Pi attached to a small LCD makes for a low-power, always-on picture frame — and a satisfying weekend project. Pick a screen that can run from the Pi's own USB port and there is no second power brick to hide.

Ingredients

Raspberry Pi

Pi 4 or Pi 5 for smooth GPU transitions. Pi Zero 2 W works too if you keep it to fades.

USB-powered LCD

A Waveshare HDMI LCD (7" 1024×600 is a sweet spot) — HDMI for video, single USB cable for power + touch.

microSD card

16 GB is plenty for the OS; pair with a USB stick or network share for the photo library.

Enclosure

A real picture frame, a 3D-printed shell, or just a desk stand — your call.

From SD card to slideshow

  1. Flash Raspberry Pi OS

    Use the Raspberry Pi Imager to write the latest 64-bit OS to your microSD. Configure Wi-Fi and SSH up front so you can work headless.

  2. Wire up the display

    HDMI cable from Pi to LCD, then a single USB cable from a Pi USB port to the screen for power and touch. No external supply needed.

  3. Install picture show 3 from source

    Clone the repo, set up a virtualenv, and pip install -r requirements.txt. Python ≥ 3.14 and PySide6 ≥ 6.7 are the only hard dependencies.

  4. Autostart on boot with systemd

    Create a small unit file that runs python main.py --background /path/to/photos. systemd brings it back automatically after a power cut — and the slideshow itself resumes the show.

  5. Open the remote URL from your phone

    Visit http://<pi-ip>:8765 on any phone or browser on the same Wi-Fi, switch to the Picture Frame tab, and press Start Show. That's it.

Tip — backlight on demand. Pair the show with the --on-show-start and --on-show-stop flags to run a command whenever the show starts or stops. On a Pi, that is the natural place to call vcgencmd display_power 1 / 0 so the LCD only consumes power while photos are actually on screen.
